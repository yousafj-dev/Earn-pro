# Earning App Starter (Flutter + Firebase)

This is a starter scaffold for a cross-platform earning-task app. It includes:
- Flutter app shell for Android + web
- Firebase email/password authentication UI
- Firestore profile creation after signup
- Firestore security rules starter
- Suggested database schema and setup steps

Important:
- The app name is a placeholder (`Earning App`) until you choose your brand name.
- Firebase configuration files are intentionally not included. They are project-specific and must be generated for your Firebase project.
- Sponsored tasks must be funded by a real sponsor/business. Do not promise guaranteed income.
- Referral rewards are not implemented as an automatic payout yet. Add them only with server-side validation (Cloud Functions or trusted backend), not client-side balance updates.
- No APK is attached because Flutter/Firebase build tools and your Firebase project credentials are required. Follow the steps below to build it.

## Free setup (computer recommended)
1. Install Flutter SDK: https://docs.flutter.dev/get-started/install
2. Install Android Studio (Android SDK) and/or VS Code.
3. Install Node.js only if you later use Firebase CLI tools.
4. Create a Firebase project at https://console.firebase.google.com/
5. In Firebase Authentication > Sign-in method, enable **Email/Password**.
6. Create a Firestore database.
7. Install FlutterFire CLI:
   ```bash
   dart pub global activate flutterfire_cli
   ```
8. From this folder, run:
   ```bash
   flutter create . --platforms=android,web
   flutter pub get
   flutterfire configure
   ```
   Select your Firebase project and Android + Web platforms. This generates `lib/firebase_options.dart`.
9. Replace the generated `lib/main.dart` with the provided `lib/main.dart` (if `flutter create .` overwrites it, restore this file from the ZIP).
10. Apply `firestore.rules` in Firebase Console > Firestore Database > Rules.
11. Run:
   ```bash
   flutter run -d chrome
   flutter run
   ```
12. Build:
   ```bash
   flutter build web
   flutter build apk --release
   ```
   APK output: `build/app/outputs/flutter-apk/app-release.apk`
   Web output: `build/web/`

## If using a phone only
You can edit/upload this source on GitHub and use GitHub Actions with Flutter setup to build the APK. Firebase setup still requires creating a Firebase project and adding the generated configuration. Android Studio/Flutter local build is easiest on a computer.

## Suggested project structure
```text
earning_app_starter/
  lib/
    main.dart
    firebase_options.dart   # generated by flutterfire configure; not included
  firestore.rules
  pubspec.yaml
  README.md
```

## Security boundaries
- Firestore rules let users read/write only their own basic profile fields.
- Client app does not create wallet balances or grant rewards.
- Keep reward calculation, task approval, referral validation, and withdrawal processing on a trusted backend (e.g. Firebase Cloud Functions).
- Never put service-account credentials or private API keys in Flutter source.
